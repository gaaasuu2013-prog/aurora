運営者はこの場にいない前提で、最後まで進めてください。

1. **update-watcher** に `data/watchlist.md` の確認と、必要な記事の更新を頼む。
2. 開いたままのプルリクエストを確認する。10日以上 Merge されていない承認待ちは、週報の先頭に「まだ承認待ち」として出す。
3. **analyst** に数字の取得と週報 `data/reports/weekly-YYYY-WW.md` の作成を頼む。
4. 週報を main にコミットして push する（記事ではないので区分に関係なく push してよい）。
5. 最後に、週報のうち次の部分だけを短く表示する（これが運営者への通知になる）。
   - 今週公開した記事（本数）
   - 承認待ち：n件（それぞれ1行：何を確認すればよいか）
   - 運営者への質問：n個
   - 条件の変更：あり / なし
