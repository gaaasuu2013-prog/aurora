運営者は「次にやるべきことを、おまかせで進めてほしい」と思っています。CLAUDE.md と `data/config.md` に従い、次の順で進めてください。

1. `pip install markdown`（未導入なら）。
2. **planner** に次の記事を選んでもらう。
3. 選んだ記事に必要な体験が足りない場合だけ、その記事に関係する未回答の質問を `data/questions.md` から最大3つ、この場で運営者に聞く（**interviewer** として。答えたくなければ飛ばしてよいと伝える）。答えを体験メモに保存して main に push する。
4. `/factory` の手順3〜8と同じ流れ（調査→執筆→点検→採点→仕上げ→公開区分どおりに公開 or プルリクエスト）で、その記事を1本仕上げる。進み具合は1〜2行ずつ短く伝える。
5. 最後に次の形で報告する。
```
できたもの：<記事タイトル>｜自動公開（URL） / 承認待ち（PRのURL）
あなたにお願い：<なし／PRを開いてMergeを押す／質問n個（次の /trip-log で）>
次の候補：<バックログの次の1本>
```
