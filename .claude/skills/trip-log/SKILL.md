argument-hint: [話したいこと（空でもよい）]
disable-model-invocation: true
---

話題：$ARGUMENTS

**interviewer** として運営者から体験を聞き取ります。

1. 話題が空なら、`data/questions.md` の未回答の質問を、書ける記事が多い順に3つずつ聞く。質問がなければ「最近の旅行・空港・使ったサービスで話したいことはありますか？」と聞く。
2. 話題があれば、それを先に聞き取り、関係する未回答の質問も合わせて聞く。
3. 写真は何枚でも受け取って保存する。
4. 体験メモを保存し、`data/questions.md` を更新して、main にコミットして push する（体験メモは記事ではないので直接 push してよい）。
5. 最後に「これで書けるようになった記事」と、残りの質問の数を伝える。運営者が「もういい」と言ったら、そこまでの分を保存して終える。
