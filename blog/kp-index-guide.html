Kp指数とは？オーロラ予報の見方と「Kpいくつで見える」の目安

公開 2026-11-01　更新 2026-11-01

この記事では、オーロラ予報の「Kp指数」の意味と読み方がわかります。 「Kpいくつで見えるか」は場所で変わり、ラップランドなどでは低いKpでも見え、北海道ではまれです。 予報は「27日予報→3日予報→当夜のOVATIONと雲」の順に確かめるのが基本です。

Kp指数とは？0〜9で表す「地磁気の乱れ」

Kp指数は、地球の磁場がどれだけ乱れているかを表す数字です。 3時間ごとに、磁力計（磁場を測る機械）の揺れの大きさから求めます。 値は0〜9で、1は静か、5以上は「磁気嵐」です。 NOAA SWPC（米国の宇宙天気予報センター）のリアルタイム値は、8か所の磁力計からの推定値です。 公式の確定値は、国際的な学会（IAGA）が認めたGFZ（ドイツ地球科学研究センター）のKpです（出典：NOAA SWPC、GFZ）。

もとになるのは、各観測所の「K指数」です。 K指数は1か所の乱れを表し、数字が1増えるごとに乱れの幅が大きく増える目盛りです。 Kpは13の観測所のK指数を標準化して平均したものです（出典：NOAA NCEI「Geomagnetic Indices」）。 磁場が大きく乱れるほど、オーロラは明るく、低い緯度まで広がります。

Kpいくつで見える？答えは「地磁気緯度」で変わる

地磁気緯度とは、地球の磁石の軸を基準にした緯度です。 オーロラの見え方は、地図の緯度ではなく地磁気緯度で決まります。

NOAAによると、オーロラ帯の南の端（地磁気緯度）はKp0で約66°です。 Kpが1上がるごとに約2°南へ動き、Kp9で約48°になります。 ただし「おおよその平均」で、厳密に成り立たない日もあります（出典：NOAA SWPC「Tips on Viewing the Aurora」）。 明るいオーロラは条件がよければ、最大 約1000km離れた場所からも見えます（出典：NOAA SWPC「Aurora - 30 Minute Forecast」）。

行き先別：オーロラが見える目安のKp（極光ナビの計算値）

下の表は、極光ナビの計算値（双極子近似）で、公的な観測値ではない目安です。 双極子近似とは、地球の磁場を1本の棒磁石とみなす計算方法です。

行き先 地磁気緯度 地平線に見える目安Kp 真上の目安Kp
トロムソ 67.5° 0 0
アビスコ 66.4° 0 0.1
ロヴァニエミ 63.6° 0 1.4
レイキャビク 68.8° 0 0
フェアバンクス 65.6° 0 0.4
イエローナイフ 68.5° 0 0
稚内 37.6° 8.6 9.7
陸別 35.8° 9.0 9.9（上限）

陸別の地磁気緯度は、名古屋大学 ISEE の資料では約36.9°で、この近似とは約1°ずれます（出典：名古屋大学 ISEE 研究集会資料）。 表の「0」は、静かな夜でもオーロラ帯に入りうる位置という意味で、出る保証ではありません。 地磁気緯度は近似の計算値なので、他の資料の値とずれることがあります。 レイキャビクがトロムソより高く出ているのも、この近似での値です。

ロヴァニエミで今夜見えそうか（0〜100の見えやすさ）は、ロヴァニエミの観測地ページで見られます。

フィンランドやノルウェーではKpが低くても見える

フィンランド気象研究所によると、暗く雲のない夜のうち、見える割合は次のとおりです。

  • キルピスヤルヴィ：75%
  • ラップランドのスキーリゾート（ユッラス、レヴィ、サーリセルカ）：約50%
  • オウル・クーサモ：約25%
  • ヘルシンキ・トゥルク：月に1回ほど

同研究所は数字のKp基準を示さず、場所ごとの「しきい値」を超えると出やすいと説明しています（出典：Finnish Meteorological Institute「Auroras in Finland」）。

ノルウェー宇宙天気センター（トロムソ大学）によると、北ノルウェーの磁場は地球全体の状態と大きくずれることがあります。 オーロラが急に明るくなる「サブストーム」は、3時間より短い時間で起きます（出典：NOSWE / UiT）。 3時間ごとのKpだけで、出る・出ないは決まりません。

日本（北海道）でオーロラが見えるKpは？

「北海道ではKpいくつ以上」という一律の数字は、公的な資料では見つかりませんでした。 1つ目の理由は、地磁気緯度が低いことです。 上の表のとおり、NOAAの平均（Kp9で約48°）より、ずっと南です。

2つ目の理由は、Kpだけで決まらない例があることです。

2024年5月の大磁気嵐 この嵐は5月10日（米国東部時間）に最大のG5に達し、NOAAは「今世紀でおそらく最強」としています（出典：NOAA SWPC、NOAA）。 5月11日には、日本の広い範囲でオーロラが写真に撮られました。 発光が高度 約1,000kmまで達したため、低い緯度からも見えたそうです（出典：国立極地研究所ほか 発表資料）。

規模の大きくない磁気嵐で見えた例 北海道大学とOISTは、2024〜2025年の5回の例を発表しました。 どれも太陽風の密度が通常の約10倍と、非常に濃い日でした。 発光は高度500〜800kmに達していました（出典：北海道大学 プレスリリース 2026-05-21）。

なお、NICTの宇宙天気予報の「地磁気」のレベルは、Kpではありません。 茨城県柿岡のK指数を5段階で表したものです（出典：NICT 宇宙天気予報）。 KとKpは混ぜて読まないようにしましょう。

Kpと磁気嵐の大きさ（G1〜G5）の対応

NOAAは、磁気嵐の大きさをG1〜G5の5段階でも表します（出典：NOAA SWPC「NOAA Space Weather Scales」）。

Gスケール Kp 11年の周期での回数（日数）
G1（Minor） 5 1700回（900日）
G2（Moderate） 6 600回（360日）
G3（Strong） 7 200回（130日）
G4（Severe） 8（9-を含む） 100回（60日）
G5（Extreme） 9 4回（4日）

かっこ内は、その強さに達した日数です。 「11年の周期」は、太陽の活動が強まって弱まる周期です。

オーロラ予報の見方：27日予報・3日予報・OVATIONの使い分け

27日予報：旅行の日程えらびの目安

27日予報には、日ごとの「最大Kp」の予報が並びます。 毎週月曜 15:00 UTC までに発表されます（出典：NOAA SWPC「27-day Outlook」）。 UTCは世界の基準時刻で、日本時間はUTC+9です（出典：NICT「日本標準時」）。 月曜15:00 UTCは、日本時間の火曜0:00です。

予報は、太陽が約27日で1回転し、活動的な領域がまた地球の正面に戻ることにもとづきます（出典：NOAA SWPC「Forecasts」）。 ただし、何週間も先の予報は難しいとされます（出典：NOAA NCEI）。 日程は「目安」として使い、Kpだけで決めないのが安全です。

3日予報：前日〜当日の判断（UTCと「4.67」の読み方）

3日予報は、3日分のKpを3時間ごとに出す文章の予報です。 00:30 と 12:30 UTC の12時間ごとに発表されます（出典：NOAA SWPC「3-Day Forecast」）。 日本時間では 9:30 と 21:30 です。

「NOAA Kp index breakdown」の表には、00-03UT〜21-00UT の8枠が3日分並びます。 UTはUTCとほぼ同じ意味の世界時です。

時刻の読み方：日本時間なら、UTに9時間足します。 たとえば「12-15UT」は、日本時間の21〜24時です。 旅行先では、その国の時差で直してください。

小数の読み方：Kpは1/3刻みの数字です（出典：NOAA NCEI）。 そのため「4.33」は「4+」、「4.67」は「5-」のことです。

たとえば2026年11月1日 12:30 UTC 発表分には、次の一文がありました。 「The greatest expected 3 hr Kp for Nov 01-Nov 03 2026 is 4.67 (NOAA Scale G1)」 3日間で最も高い3時間のKpは4.67（5-）で、G1相当という意味です（出典：NOAA SWPC 3日予報テキスト）。

OVATION：「今、外に出るか」

OVATIONは、オーロラの位置と強さを示す地図の予報です。 ジョンズ・ホプキンス大学の研究所が作ったモデルで、NOAAは2020年に新しい版を運用に入れました。 先読みは「30〜90分先」で、地図の「確率」はオーロラの強さから出した推定です（出典：NOAA SWPC「Aurora - 30 Minute Forecast」）。 なお、NOAAの予報図にあった見える南の限界の線「ビューライン」は、2026年5月に削除されました（出典：NOAA SWPC「Aurora - Tonight and Tomorrow Night」）。

Bzと太陽風の速さ：「いま出るか」の手がかり

Kpは3時間ごとなので、「今」を見るには太陽風のデータを使います。

Bzは、太陽風が運ぶ磁場の南北の向きです。 南向き（マイナス）の磁場は、太陽風のエネルギーを地球の磁気圏へ運びやすくします。 磁気嵐には、この南向きの磁場と、高速の太陽風が数時間以上続くことが重要とされます（出典：NOAA SWPC「Geomagnetic Storms」）。 NICTも、南向きになるとオーロラが明るくなると説明しています（出典：NICT オーロラ・アラート）。

太陽風の速さは、ふつう約400km/sです。 コロナホール（太陽の暗い領域）からの高速の風は、500〜800km/sになります（出典：NOAA SWPC「Solar Wind」）。 NOAAのグラフではBzがマイナスの部分に色がつきますが、「何nTならよい」という公式の基準は確認できませんでした（出典：NOAA SWPC「Real Time Solar Wind」）。

Kpが高くても見えない条件（雲・月明かり・暗さ）と寒さ対策

Kpが高くても、空の条件が悪いとオーロラは見えません。

  • 雲：晴れていることが必要です。雲は天気予報で確認します。
  • 暗さ：暗い空が必要です。オーロラ帯の夏は白夜で見えません。
  • 月明かり：満月は空を明るくし、オーロラの「見かけの」明るさを下げます。
  • 街明かり：見え方に影響します。
  • 時間帯：よく見えるのは、真夜中の前後1〜2時間（現地時間22時〜2時）です。
  • 季節：春分・秋分のころがよいとされます。

（出典：NOAA SWPC「Tips」、NOAA SWPC「Aurora」、NOAA NCEI）

オーロラを待つ夜は冷え込むので、長く外にいるつもりで服装を整えましょう。 凍傷の初期サインは、チクチクする感じや、感覚がなくなることです（出典：Terveyskirjasto「Paleltuma」）。 服装と持ち物はオーロラ旅の服装と持ち物にまとめています。

オーロラ予報を確かめる手順（チェックリスト）

  1. 日程を決めるとき：27日予報　日ごとの最大Kpを目安にし、暗い時間の長さと月明かりも合わせて考えます。
  2. 前日〜当日：3日予報　3時間ごとのKpを日本時間・現地時間に直し、夜の枠の値を見ます。
  3. 当夜：OVATIONと雲　OVATIONで30〜90分先を見て、雲の予報で晴れ間を確かめます（極光ナビで雲量を見る）。

極光ナビは何を使って判定している？

極光ナビの「見えやすさ」は、磁気活動×暗さ×晴れ×月明かりで出すスコアで、確率ではありません。 磁気活動は、上の表と同じ「地平線・真上の目安Kp」をKp予報と比べ、磁場 Bz と太陽風速度も表示しています。 地図の「いま見えていそう」はOVATION・暗さ・雲量で判定し、OVATIONが取れないときはKpから推定します。

極光ナビ：Kp予報・雲量・暗さ・月明かりをまとめて判定し、今夜の見えやすさを表示します。

まとめ

  • Kpは、地球全体の磁場の乱れを0〜9で表す3時間ごとの数字です。5以上が磁気嵐です。
  • 「Kpいくつで見えるか」は地磁気緯度で変わり、北海道に一律の数字はありません。
  • 予報は27日予報→3日予報→当夜のOVATIONと雲の順に確かめます。時刻はUTCです。
  • Kpが高くても、雲・月明かり・暗さがそろわないと見えません。
